# Thumbnail prompts for pv's mods

One prompt per mod for a text-to-image model (ChatGPT / GPT Image, Gemini, Midjourney, Ideogram, Flux…).
Generate each at **16:9** (landscape, at least 1280×720) and save it as **`<mod id>.png`** (or `.jpg` / `.webp`),
e.g. `582909.png`. Put the files in `mod-thumbs/` (or send them in chat). They replace the drawn SVG thumbnails;
the site shrinks them to small web copies.

Every prompt ends with the same style line, so the set looks like one family. If a model adds text or logos anyway,
regenerate: the page already shows each mod's name.

**Style line (already included below):** *Painterly digital illustration in the spirit of a classic medieval
real-time-strategy loading screen, high three-quarter bird's-eye view, rich detail, warm cinematic light, crisp
focal point in the centre, 16:9. No text, no letters, no numbers, no logos, no UI, no watermark.*
